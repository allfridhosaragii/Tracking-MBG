- Installer memeriksa SHA commit setelah clone.
- Integrator memeriksa SHA256 setiap file skill yang disalin terhadap source clone.
- **Tidak** mengklaim SHA256 upstream dicocokkan dengan keaslian penerbit melalui tanda tangan kriptografis. Git SHA cocok dengan commit repo yang direferensikan.
- Untuk update: riset perubahan aturan, catat diffs, audit kembali fitur dan unit tests; jangan memasang HEAD terbaru secara diam-diam.
